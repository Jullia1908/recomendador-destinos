# Recomendador de Destinos

Projeto de console em Python desenvolvido durante o ensino médio. O programa conversa com o usuário e recomenda destinos de viagem a partir de escolhas como orçamento, época do ano, tipo de lugar e atividade preferida.

## Como funciona

O fluxo utiliza perguntas e estruturas condicionais para combinar as preferências informadas. Entre os destinos apresentados estão cidades e atrações nacionais e internacionais.

## Como executar

É necessário ter o Python 3 instalado. No terminal, entre na pasta do projeto e execute:

```bash
python recomendador_destinos.py
```

Depois, responda às perguntas usando os números exibidos pelo programa.

O projeto foi criado como exercício de lógica de programação e representa uma etapa inicial do meu aprendizado em Python.
